Final-phase checks (NOT run in the no-launch phase):
1. Build+run with the self-host compiler (macx64_guards.srp):
   program output must match the one line above byte-for-byte. This is
   a mirror fixture (it re-implements the guarded size-arithmetic
   kernels of compiler/macx64.sr in user code rather than importing
   the compiler module, following the resource_adaptive /
   cli_flags_holder / watch_scan_files pattern), so it runs
   identically on every host.
2. Byte-identity: every guard added to compiler/macx64.sr is a no-op
   for valid inputs (non-positive divisor and negative values never
   occur on the driver path, which passes PAGE=4096 and real array
   lengths; nsects is 0/1; the layout always has 9 slots), so
   --os macx64 images are byte-identical before/after. In the final
   phase, hash a macx64 target binary built from the same source
   before and after the commit and diff.
3. Negative (future-regression proof): mutate any kernel in main.sr
   (e.g. dropping the saturation in mirrorAlignUp, or the nImp cap)
   — the fixture must fail with exit code 1. That is the property a
   future edit breaking compiler/macx64.sr's guards would violate.
4. Measurement: none applicable at byte level — the guards are O(1)
   scalars with no new allocation, so there is no peak-RSS number to
   move; the fixture is the proof, not a bench. Layout-overflow
   bench (a near-int64 nImports row) is pinned by the huge-plan
   checks above.
